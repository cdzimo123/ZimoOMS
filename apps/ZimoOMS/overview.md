# 《经销订单全流程》

面向品牌方/工厂管理「经销商下单 → 上门测量 → 同步工厂生产 → 物流发货 → 上门安装 → 售后 → 应收回款」的完整业务闭环（HAP / 明道云零代码应用，多端一体：PC 网页端 + 移动 App + H5/小程序入口）。

应用：ZimoOMS（appId `46eecd9f-8c9e-4049-80f6-388d09e45ee3`，org `a526cdaf-65b7-407f-9412-e415136d9038`）

## 角色（9）
订单专员、测量员、生产跟单员、物流专员、售后专员、应收专员、管理层（只读）、安装师傅（外部门户）、经销商（外部门户）。

## 工作表（12）
- 资料：经销商、产品、工厂
- 订单：订单、订单明细
- 交付：测量单、生产单、物流单、安装单
- 售后应收：售后工单、收款计划、收款记录

关联关系：经销商 1—* 订单；订单 1—* 订单明细（*—1 产品）；订单 1—* 测量单/生产单(*—1 工厂)/物流单/安装单/售后工单/收款计划/收款记录；收款计划 1—* 收款记录。

## 自定义动作（11）
- 订单：派工测量 / 同步工厂 / 安排发货 / 派工安装 / 登记回款（按订单状态启用）
- 测量单：提交测量结果；生产单：更新生产进度；物流单：确认发货
- 安装单：提交安装结果 / 确认验收；售后工单：提交处理结果

## 视图（30）
各表含「全部」视图，并按业务补充看板/筛选视图（订单生产交付跟踪看板、待审核、待收款；测量/生产/安装/售后看板与待办；逾期应收；产品图册等）。

## 自定义页面（5）
- 经营总览看板（dashboard）：订单总数/销售总额/已回款/未回款 + 状态分布/经销商销售额/月度趋势/金额透视
- 应收回款看板（dashboard）：应收/已收/未收/回款笔数 + 收款状态分布/各节点应收/回款趋势
- 订单作业台（workspace，订单专员）
- 经销商门户（workspace，外部经销商）
- 安装任务台（workspace，外部安装师傅）

## AI 助手（1）
订单助手：查询订单进度、交期、应收对账与售后状态。

## 自动化工作流（设计）
订单审核流、测量完成联动、生产完工联动、物流签收联动、安装验收联动、回款汇总联动、应收逾期预警、售后超时升级。

> 物理搭建通过 `hap-mcp-ZimoOMS` MCP 服务执行；各对象 ID 见 `hap-context.json`，字段结构见 `worksheetContext.json`。
